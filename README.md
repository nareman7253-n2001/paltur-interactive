# PalTur Interactive Platform | منصة بالتور التفاعلية

## [English]
PalTur is a comprehensive interactive web platform designed to enhance city accessibility and community engagement.

### Key Features:
- **Full RTL Support:** Seamlessly switches between Arabic and English with dynamic sidebar positioning.
- **ASP.NET Core 8 Backend:** Robust backend with PostgreSQL and JWT authentication.
- **Content Management System (CMS):** Easy-to-use dashboard for real-time content updates.
- **Accessibility Focus:** Specialized tools for people with disabilities, including accessible path mapping and obstacle reporting.
- **Interactive Map:** Real-time city overview with traffic and event layers.

---

## [العربية]
بالتور هي منصة ويب تفاعلية شاملة مصممة لتعزيز إمكانية الوصول إلى المدينة والمشاركة المجتمعية.

### المميزات الرئيسية:
- **دعم كامل للغة العربية (RTL):** تبديل سلس بين العربية والإنجليزية مع تغيير موضع الشريط الجانبي ديناميكياً.
- **خادم ASP.NET Core 8:** بنية خلفية قوية مع قاعدة بيانات PostgreSQL ومصادقة JWT.
- **نظام إدارة المحتوى (CMS):** لوحة تحكم سهلة الاستخدام لتحديث المحتوى في الوقت الفعلي.
- **التركيز على إمكانية الوصول:** أدوات متخصصة لذوي الاحتياجات الخاصة، تشمل خرائط المسارات الميسرة والإبلاغ عن العوائق.
- **خريطة تفاعلية:** نظرة عامة لحظية على المدينة مع طبقات للمرور والفعاليات.

## Getting Started | ابدأ العمل

1. **Frontend:**
   ```bash
   cd artifacts/urban-up
   pnpm install
   pnpm dev
   ```

2. **Backend:**
   ```bash
   cd PalTur.Api
   dotnet restore
   dotnet run
   ```
